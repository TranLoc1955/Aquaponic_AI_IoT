📡 Test luồng IoT → Web (từng bước)

Mô phỏng thiết bị IoT đẩy JSON lên server → server lưu, so sánh ngưỡng, tạo cảnh báo → web nhận và hiển thị.

IoT gửi JSON→ API nhận & lưu dulieucambien→ So sánh ngưỡng → tạo canhbao (nếu vượt)→ Web gọi API → hiển thị dữ liệu & thông báo

0 Thông tin kết nối

1 IoT đẩy dữ liệu (JSON) – như thiết bị gửi lên

Chỉnh JSON bên dưới giống payload IoT gửi. Trường id = idthietbi thiết bị. Sau đó bấm "Gửi như IoT".

(chưa gửi)

2 Server đã nhận → Lưu vào dulieucambien & so sánh ngưỡng → Tạo canhbao nếu vượt

Kết quả bước 1 chính là response của server: đã lưu và (nếu có) đã tạo cảnh báo. Nếu thấy "status": "success" là ổn.

Chạy Bước 1 trước, kết quả sẽ hiển thị ở Bước 1 và được tóm tắt ở đây.

3 Web lấy dữ liệu đã lưu (như Dashboard tổng quan)

Gọi API tổng quan để xem dữ liệu cảm biến mới nhất đã lưu (nhiệt độ, độ ẩm, pH, ánh sáng).

(chưa gọi)

4 Web lấy thông báo cảnh báo (như chuông thông báo)

Gọi API cảnh báo để xem danh sách thông báo (đã tạo ở bước 1 nếu giá trị vượt ngưỡng).

(chưa gọi)
